# 🇻🇳 Hướng dẫn sử dụng CashClaw / 🇬🇧 CashClaw User Guide

---

## Đăng nhập / Login

1. Mở trình duyệt, truy cập URL CashClaw mà bạn nhận được.
2. Nhập **email** của bạn.
3. Nhập **mã passcode** 6 chữ số (gửi qua email hoặc Telegram).
4. Nhấn **Đăng nhập**.

> 🔐 Nếu không nhận được mã, kiểm tra hòm thư spam hoặc liên hệ hỗ trợ.

1. Open your browser, go to your CashClaw URL.
2. Enter your **email** address.
3. Enter the **6-digit passcode** (sent via email or Telegram).
4. Click **Login**.

> 🔐 If you didn't receive the code, check spam folder or contact support.

## Tạo Bot mới / Create a New Bot

1. Từ trang Dashboard, nhấn **Tạo bot** (hoặc vào menu Bot → Tạo bot mới).
2. Chọn **chiến lược** (Grid hoặc Mean Reversion).
3. Nhập **cặp giao dịch** (ví dụ: BTC/USDT).
4. Nhập **số vốn** muốn phân bổ (đơn vị USD).
5. Nhấn **Tạo bot**.

Bot sẽ chạy ở chế độ **Paper Trading** — giả lập giao dịch, không dùng tiền thật.

1. From Dashboard, click **Create bot** (or go to Bots → Create new bot).
2. Choose a **strategy** (Grid or Mean Reversion).
3. Enter a **trading pair** (e.g., BTC/USDT).
4. Enter the **capital** you want to allocate (in USD).
5. Click **Create bot**.

Bot will run in **Paper Trading** mode — simulated trades, no real money at risk.

## Xem Dashboard / View Dashboard

Trang Dashboard hiển thị:
- **Tổng tài sản** — giá trị portfolio hiện tại
- **Lãi/Lỗ hôm nay** — P&L trong 24h
- **Bot hoạt động** — số bot đang chạy
- **Tỷ lệ thắng** — win rate tổng

Dashboard shows:
- **Portfolio Value** — current portfolio value
- **Today's P&L** — profit/loss in 24h
- **Active Bots** — number of running bots
- **Win Rate** — overall win rate

## Dừng khẩn cấp (Kill Switch) / Emergency Halt

Nếu muốn dừng **tất cả bot** ngay lập tức:

1. Vào **Cài đặt** (Settings).
2. Cuộn xuống phần **Dừng khẩn cấp**.
3. Nhấn **Emergency Halt**.
4. Tất cả bot sẽ dừng giao dịch ngay lập tức.

Để tiếp tục: nhấn **Resume Trading** trong cùng phần.

To **stop all bots** immediately:

1. Go to **Settings**.
2. Scroll to **Emergency Halt** section.
3. Click **Emergency Halt**.
4. All bots will stop trading immediately.

To resume: click **Resume Trading** in the same section.

## Nhập API Key sàn / Enter Exchange API Keys

> ⚠️ **Lưu ý:** Hiện tại CashClaw chạy ở chế độ **Paper Trading**. API key chỉ cần khi bạn muốn nâng cấp lên chế độ Live trong tương lai.

1. Vào **Cài đặt** → **Exchange Credentials**.
2. Chọn sàn (Binance, Bybit, hoặc OKX).
3. Nhập **API Key** và **API Secret**.
4. Nhấn **Cập nhật**.

> 🔐 API key được mã hoá và lưu an toàn. CashClaw không thể rút tiền từ tài khoản của bạn.

> ⚠️ **Note:** CashClaw currently runs in **Paper Trading** mode. API keys are only needed if you upgrade to Live mode in the future.

1. Go to **Settings** → **Exchange Credentials**.
2. Select your exchange (Binance, Bybit, or OKX).
3. Enter your **API Key** and **API Secret**.
4. Click **Update**.

> 🔐 API keys are encrypted and stored securely. CashClaw cannot withdraw funds from your account.

## Giới hạn rủi ro / Risk Limits

Trong **Cài đặt** → **Risk Limits**, bạn có thể đặt:

- **Max Drawdown (%)** — mức lỗ tối đa chấp nhận được trước khi bot dừng.
- **Daily Loss Limit (%)** — giới hạn lỗ trong ngày.

Trong **Settings** → **Risk Limits**, you can set:

- **Max Drawdown (%)** — maximum loss before bot auto-stops.
- **Daily Loss Limit (%)** — daily loss cap.

## Đăng xuất / Logout

Nhấn **Đăng xuất** ở menu bên trái. Phiên đăng nhập sẽ hết hạn sau 7 ngày.

Click **Logout** in the left menu. Your session expires after 7 days.
