# CashClaw Trademark & Brand Policy

## 1. Purpose
CashClaw is an Open-Core project. While our core quantitative libraries (`src/tree/quantlib`, `src/tree/research/alpha/zoo`) and paper-trading engine are open-source under **Apache-2.0**, the **CashClaw** wordmark, logos, and Cloud SaaS identity are protected trademarks.

## 2. Permitted Uses (No Approval Required)
- Stating truthfully that your project or research paper is "Built on CashClaw QuantLib" or "Compatible with CashClaw Open-Core".
- Linking to the official GitHub repository or official CashClaw Cloud SaaS.
- Running unmodified or modified Apache-2.0 core code for internal research, academic work, or personal paper trading.

## 3. Prohibited Uses (Without Written Permission)
- Offering a hosted commercial trading/research SaaS using the name **"CashClaw"**, **"CashClaw Cloud"**, or confusingly similar branding.
- Implying official endorsement by CashClaw for third-party investment funds, live-trading bots, or token sales.
- Removing attribution headers from Apache-2.0 files.
