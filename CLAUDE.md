# CLAUDE.md This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository. ## Identity **trade-bot** — "CashClaw AI Trading Bot Platform". Next.js 16 App Router app for AI-driven trading workflows, using Cloudflare Workers via Wrangler. Customer-facing product with bilingual UI (Vietnamese + English) through `next-intl`; default locale is `vi`. ## Commands Run from this project root: ```bash npm run dev # Next.js dev server npm run build # Production build npm run lint # ESLint npm run type-check # tsc --noEmit npm test # Vitest npx vitest run <path> # run one test file/pattern npm run db:generate # create local D1 migration npm run db:apply # apply local D1 migrations npm run db:apply:remote # apply remote D1 migrations npm run deploy # deploy with Wrangler ``` ## Architecture App Router under `src/app/[locale]` with global middleware that bypasses API routes and redirects to `vi` by default. Core app code lives in `src/app`, `src/components`, `src/forest`, `src/land`, `src/tree`, `src/i18n`, `src/lib`, and `src/messages`; `src/worker.ts` defines the Worker entry. Domain logic separates into workflow layers rather than feature folders; treat these boundaries as contract seams and prefer existing imports over adding another cross-layer coupling. ## Hard rules Keep the working tree clean before deploy commands. Preserve existing route and API contracts unless the request explicitly updates them. Keep secrets, API keys, and tokens in environment config only; do not add them in code or commands. Do not reference an installed MCP server as if its tooling is always available; feature-detect before relying on external capabilities.
